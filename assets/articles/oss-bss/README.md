# OSS і BSS

Чотири інтерактивні статті на спільному рушії схем:

- `index.html` — **OSS і BSS**: контури, TM Forum (ODA, eTOM, Open API), обмін даними, вендори.
- `agentic/index.html` — **Агентний AI поверх OSS/BSS**: складові агента, L0–L5, стек і сценарії, MCP / A2A-T / TMF921, вендори й кейси, межі.
- `support-chat/index.html` — **Чат-бот підтримки на OpenAI**: теми для бота, архітектура, сценарії, безпека, впровадження, метрики.
- `support-voice/index.html` — **Голосовий бот першої лінії на OpenAI**: голос проти чату, дві архітектури (Realtime / ланцюжок), шлях дзвінка, правила й безпека, якість голосу, впровадження.

## Структура

- `shared/css/` — токени Itspired, базові стилі, стилі схем, спільні компоненти (кейси, матриця повноважень).
- `shared/js/diagram-engine.js` — рушій шаруватих схем: розкладка, траси дротів жолобами, згортання смуг, хмарки, підсвітка (зокрема кроки «рішення людини» й «згода клієнта», альтернативні шляхи `paths` з перемикачем), перевірки геометрії.
- `shared/js/scenarios.js`, `shared/js/i18n.js` — покрокові сценарії й мова.
- `js/`, `data/`, `copy.csv` — стаття 1.
- `agentic/…` — стаття 2; `support-chat/…` — стаття 3; `support-voice/…` — стаття 4 (та сама структура).

## Тексти

```bash
node tools/build-copy.mjs
```

Збирає `copy.csv → copy.js` для всіх статей (або одну: `node tools/build-copy.mjs agentic`).
Після збірки підняти `copy.js?v=N` у відповідному `index.html`. Порожня клітинка `en` падає на українську.

## Перевірка схем

У консолі браузера: `OSSBSS.check()` на статті 1 (4 стани смуг) `AGENTIC.check()` на статті 2 (16 станів), `CHAT.check()` на статті 3 (8 станів), `VOICE.check()` на статті 4 (32 стани × 2 шляхи).
Порожні масиви й `roundtrip: true` — геометрія в порядку.

Стан зі адреси для знімків: `?open=1`, `?flow=<id>&step=N`, `?vendor=<id>`, `?path=pipe`.
